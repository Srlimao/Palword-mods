# HUD Locator All in 1

A clean, customizable on-screen 3D locator for Palworld that highlights **Pals**, **players**, **Lifmunk Effigies**, **chests**, **Pal eggs**, **dungeons**, **journals**, and **loot**. Includes an interactive **Regional Progress Tracker** with real-time **in-game HUD repositioning and scaling**.

🎨 **Visual Web Configurator**: Easily adjust colors, sliders, and options with a live preview at [https://pal-mod-configurator.dunhas.com/](https://pal-mod-configurator.dunhas.com/) (openable directly in-game!).

---

## Features

- 🏆 **Regional Progress & Collectables Tracker**: Live HUD overlay tracking Lifmunk Effigies, Fast Travel points, Alpha Pals, Boss Towers, and Bounties per region and global save progress.
- 🎯 **Interactive In-Game Repositioning (Alt + F7)**: Seamlessly move and reposition the tracker HUD card anywhere on screen using Arrow keys with smooth hold-acceleration.
- 🔍 **Live HUD Scaling & Presets**: Dynamically scale the tracker (`0.5x` - `2.0x`) using `+` / `-` keys or choose instant corner presets (*Top-Right*, *Top-Left*, *Bottom-Right*, *Bottom-Left*) in the menu.
- 🐾 **Advanced Pal Tracker**: Locate specific wild & boss Pals by species, Lucky/Shiny status, Alpha/Boss status, and level.
- 🧬 **Passive Skill Filtering**: Filter Pals by specific passive skills (e.g., *Swift*, *Legend*, *Runner*) with customizable minimum passive match thresholds.
- 📍 **Player Tracker**: Displays server players and real-time distances.
- 🗿 **Lifmunk Effigies**: Highlights nearby relics.
- 📦 **Treasure Chests**: Shows chest locations, tiers/grades, and distances.
- 🥚 **Pal Eggs**: Displays egg type/size with filters (All, Large+, Huge Only, Off).
- 🏰 **Dungeon Entrances**: Marks active dungeon caves.
- 📜 **Journals & Lore Memos**: Marks uncollected journals and note pickups.
- 💎 **Ground Loot**: Shows dropped items like spheres, skill fruits, arrows, and gold.
- ⚙️ **In-Game Menu (Alt + F6)**: Toggle features, filter modes, choose placement presets, and tweak distances live.
- 🔄 **Quick Reload / Reset (Alt + R)**: Reset HUD position when in edit mode, or reload config settings instantly without restarting.
- 🌐 **Multi-Language**: Automatically supports English, Chinese, Spanish, German, French, Japanese, and 10+ languages.

---

## Controls

- **Alt + F6**: Open / close in-game settings menu.
- **Alt + F7**: Toggle interactive HUD Edit Mode (move/scale tracker card).
- **Arrow Keys**: Move menu selection or move HUD card (in Edit Mode).
- **+ / -** (or **[ / ]**): Scale HUD card size (in Edit Mode).
- **Alt + R**: Reset HUD position to default (in Edit Mode) or reload config from file (in game).

### 主要功能

- 🏆 **区域全收集进度追踪 HUD**：实时显示当前区域翠叶鼠雕像、传送点、头目帕鲁、高塔Boss及赏金目标的收集与击败进度。
- 🎯 **游戏内实时调整位置 (Alt + F7)**：一键进入编辑模式，使用方向键可在屏幕上任意平滑移动 HUD 卡片（支持长按加速）。
- 🔍 **自由缩放与角隅预设**：在编辑模式下按 `+` / `-` 键即时缩放（0.5x - 2.0x），或在菜单中一键切换预设（右上、左上、右下、左下）。
- 🐾 **高级帕鲁追踪**：按物种、幸运/闪光、头目/Boss 状态及等级定位野外帕鲁与 Boss。
- 🧬 **被动词条筛选**：可按具体被动词条（如*神速*、*传说*、*跑者*）及最小匹配数量精准筛选目标帕鲁。
- 📍 **玩家定位**：实时显示服务器内玩家名字与距离。
- 🗿 **翠叶鼠雕像**：高亮标注遗物位置。
- 📦 **宝箱标记**：清晰标注各类宝箱等级品质与距离。
- 🥚 **帕鲁蛋追踪**：显示种类与尺寸，支持筛选（全部、大型+、仅限巨大、关闭）。
- 🏰 **地下城入口**：标注可进入的洞穴入口。
- 📜 **日志/笔记**：标注未收集的日志与便签。
- 💎 **地面掉落**：标注帕鲁球、技能果实、箭矢、金币等掉落物。
- ⚙️ **内置菜单 (Alt + F6)**：游戏内随心开关功能、切换模式、选择位置预设与实时调节距离。
- 🔄 **一键重载 / 重置 (Alt + R)**：编辑模式下一键恢复默认位置，平时可一键免重启刷新配置。
