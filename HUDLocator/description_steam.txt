[h1]HUD Locator[/h1]

A client-side UI mod for Palworld that displays customizable floating 3D HUD overlays for [b]players[/b], [b]Lifmunk Effigies (relics)[/b], [b]treasure chests[/b], [b]Pal eggs[/b], [b]dungeons[/b], and [b]ground loot[/b].

🎨 [b]Visual Web Configurator[/b]: Tweak colors, sliders, padding, and fonts with a live HUD preview at [url=https://pal-mod-configurator.dunhas.com/]https://pal-mod-configurator.dunhas.com/[/url] (can be opened directly from the in-game menu!).

[hr][/hr]

[h1]Key Features[/h1]

[list]
[*] [b]Player Tracker[/b]: Server-wide names and real-time distances.
[*] [b]Relic Finder[/b]: Cyan overlays for Lifmunk Effigies.
[*] [b]Chest Finder[/b]: Yellow/gold overlays for treasure chests.
[*] [b]Pal Egg Finder[/b]: Displays size/type with filters (All, Large+, HugeOnly, None).
[*] [b]Dungeon Finder[/b]: Purple overlays for dungeon cave entrances.
[*] [b]Journal / Note Tracker[/b]: Coral/salmon overlays for uncollected lore journals/memos.
[*] [b]Ground Loot Tracker[/b]: Green overlays for wild spheres, skill fruits, arrows, coins (Filter in [b]config.json[/b]).
[*] [b]In-Game Menu (Alt + F6)[/b]: Toggle trackers and adjust distances on the fly.
[*] [b]Manual Reload (Alt + R)[/b]: Reload settings instantly from JSON config.
[*] [b]Localization[/b]: Automated translations (English, Chinese, Spanish, Japanese, French, German, and 10+ more).
[/list]

[hr][/hr]

[h1]In-Game Controls[/h1]

[list]
[*] [b]Alt + F6[/b]: Toggle settings menu.
[*] [b]Alt + Up/Down/Left/Right[/b]: Navigate menu and adjust values.
[*] [b]Alt + R[/b]: Reload configuration from settings file.
[/list]

[hr][/hr]

[h1]Requirements[/h1]

[/list]
