[h1]HUD Locator[/h1]

A client-side UI mod for Palworld that displays customizable floating 3D HUD overlays for [b]players[/b], [b]Lifmunk Effigies (relics)[/b], [b]treasure chests[/b], [b]Pal eggs[/b], and [b]dungeon entrances[/b]. 

[hr][/hr]

[h1]Key Features[/h1]

[list]
[*] [b]Player Tracker[/b]: Displays names and real-time distances server-wide (even beyond standard network replication distance). Supports nameplate backgrounds or simple text overlays.
[*] [b]Relic Finder[/b]: Highlights nearby Lifmunk Effigies with cyan tags.
[*] [b]Chest Finder[/b]: Highlights unopened treasure chests with yellow/gold tags.
[*] [b]Pal Egg Finder[/b]: Displays egg size (Huge, Large, etc.) and type (e.g. Scorching Egg). Includes distance filter options ([b]All[/b], [b]Large+[/b], [b]HugeOnly[/b], [b]None[/b]).
[*] [b]Dungeon Finder[/b]: Highlights fixed dungeon cave entrances with purple tags.
[*] [b]Ground Loot & Pickup Tracker[/b]: Highlights naturally spawned items on the ground (like wild Pal Spheres, Skill Fruits/Cards, gold coins, upgrade stones, arrows) with a light-green label. You can customize which items are shown by editing the [b]"Filters"[/b] list in [b]config.json[/b] (e.g. [b]"Filters": ["Sphere", "Flower"][/b]).
[*] [b]In-Game Settings Menu[/b]: Toggle trackers, adjust egg filters, or set max tracking distance directly in-game using a built-in menu ([b]Alt + F6[/b]).
[*] [b]Manual Config Reload[/b]: Reload configurations instantly via [b]Alt + R[/b] from the external settings JSON file.
[*] [b]Visual Web Configurator[/b]: Tweak detailed styles (colors, sliders, padding, fonts) with a live HUD preview using the web editor: [url=https://pal-mod-configurator.dunhas.com/]https://pal-mod-configurator.dunhas.com/[/url]. Can be opened directly from the in-game menu.
[*] [b]Localization[/b]: Supports English, Chinese, Spanish, Japanese, French, German, and 10+ other languages, auto-detected from game language settings.
[/list]

[hr][/hr]

[h1]In-Game Controls[/h1]

[list]
[*] [b]Alt + F6[/b]: Toggle in-game settings menu.
[*] [b]Alt + Up/Down/Left/Right[/b]: Navigate settings menu and modify values.
[*] [b]Alt + R[/b]: Reload configuration from settings file.
[/list]

[h1]Chinese Description[/h1]

在 3D 空间中定位玩家、翠叶鼠雕像、宝箱、帕鲁蛋和地下城入口。

[b]主要功能[/b]

[list]
[*] [b]玩家追踪[/b]：显示服务器范围内的玩家名牌与实时距离，支持带框背景或纯文本样式。
[*] [b]翠叶鼠雕像定位[/b]：显示青色遗物标签。
[*] [b]宝箱追踪[/b]：显示金色宝箱标签。
[*] [b]帕鲁蛋定位[/b]：显示蛋的类型及尺寸（巨大、大型等），支持过滤设置（全部、大型+、仅限巨大、无）。
[*] [b]地下城追踪[/b]：显示紫色地下城入口标签。
[*] [b]地面掉落与拾取物追踪[/b]：显示地面上自然生成的道具（如野生帕鲁球、技能果实/技能卡、金币、属性提升药、箭矢等），配有淡绿色标签。您可以通过编辑 [b]config.json[/b] 里的 [b]"Filters"[/b] 列表自定义要显示的物品（例如 [b]"Filters": ["Sphere", "Flower"][/b]）。
[*] [b]游戏内设置菜单 (Alt + F6)[/b]：无需退出游戏，即可在游戏中开启/关闭追踪器、调整蛋过滤和追踪距离。
[*] [b]配置快速重载 (Alt + R)[/b]：快速重新加载配置文件。
[*] [b]网页可视化配置[/b]：通过菜单可直接访问网页端工具 [url=https://pal-mod-configurator.dunhas.com/]https://pal-mod-configurator.dunhas.com/[/url] 调整样式并提供实时 HUD 预览。
[*] [b]多语言支持[/b]：根据游戏语言自动切换翻译（支持英文、中文、日文、西班牙文、德文、法文等10多种语言）。
[/list]

[b]快捷键[/b]

[list]
[*] [b]Alt + F6[/b]：开启/关闭内置设置菜单。
[*] [b]Alt + 方向键[/b]：在菜单中选择项目并调整参数。
[*] [b]Alt + R[/b]：从配置文件重新加载配置。
[/list]
