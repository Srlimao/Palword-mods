[h1]Accessory Toggler (Dedicated Server Compatible)[/h1]
A lightweight, server-synchronized, and highly performant hotbar overlay that lets you toggle your equipped accessories (like the [b]Ring of Mercy[/b], [b]Ability Glasses[/b], [b]Pendants[/b], or [b]Undershirts[/b]) directly using customizable keybinds!

Fully compatible with [b]Singleplayer[/b], [b]Local Co-op[/b], and [b]Dedicated Servers[/b]. No stat or passive skill desyncs!
[hr]
[h2]✨ Key Features[/h2]
[list]
[*] [b]Direct Keyboard Hotkeys[/b]: Press [b]5, 6, 7, or 8[/b] directly to toggle the accessory in slots 1, 2, 3, or 4 instantly.
[*] [b]Full Dedicated Server Sync[/b]
[*] [b]Interactive Edit Mode[/b]: Press [b]Alt + F7[/b] to enter Edit Mode. Use the [b]Arrow Keys[/b] to move the hotbar anywhere on your screen, and [b]+ / -[/b] to scale the hotbar size on the fly. Exit Edit Mode via Alt+F7 to automatically save settings!
[*] [b]Configurable Settings[/b]: Customize colors, scales, check intervals, and friendly item name mappings in [code]config.json[/code]. Turn off debug console spam easily by setting [code]"Debug": false[/code]
[/list]
[hr]
[h2]⌨️ Controls[/h2]
[list]
[*] [b]5[/b]: Toggle Accessory Slot 1
[*] [b]6[/b]: Toggle Accessory Slot 2
[*] [b]7[/b]: Toggle Accessory Slot 3
[*] [b]8[/b]: Toggle Accessory Slot 4
[*] [b]Alt + F7[/b]: Enter/Exit HUD Edit Mode
    [list]
    [*] [b]Arrow Keys (Up/Down/Left/Right)[/b]: Move Hotbar
    [*] [b]Plus (+)[/b]: Increase Scale
    [*] [b]Minus (-)[/b]: Decrease Scale
    [*] [b]Alt + F7[/b]: Exit & Save Changes
    [/list]
[/list]
[hr]
[h2]🛠️ Installation[/h2]
[list]
[*] Make sure you have [b]UE4SS[/b] (v3.0.0 or higher) installed.
[*] Go to Mod Settings in-game and enable both UE4SS and the mod.
[*] Game will restart.
[/list]
