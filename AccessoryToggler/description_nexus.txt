[size=5][b]Accessory Toggler[/b][/size]

Instantly toggle equipped accessories (like the [i]Ring of Mercy[/i] or thermal underwear) using hotkeys without opening your inventory!

🎨 [b]Visual Web Configurator[/b]: Easily adjust colors, positions, and options with a live preview at [url=https://pal-mod-configurator.dunhas.com/]https://pal-mod-configurator.dunhas.com/[/url]!

[hr][/hr]

[size=4][b]Features[/b][/size]

[list]
[*] ⚡ [b]Instant Hotkey Swapping[/b]: Toggle accessory slots 1–4 on the fly (Default: [b]5[/b], [b]6[/b], [b]7[/b], [b]8[/b]).
[*] 👁️ [b]Toggle HUD Visibility[/b]: Press [b]Alt + H[/b] to show or hide the HUD anytime.
[*] 📐 [b]In-Game HUD Layout Editor[/b]: Press [b]Alt + F7[/b] to reposition with arrow keys and adjust scale with [b]+[/b] / [b]-[/b].
[*] 🔢 [b]Custom Slot Count[/b]: Set [b]SlotsToShow[/b] (1 to 4) to match your active equipped accessory count.
[*] 🔄 [b]Quick Reload[/b]: Press [b]Alt + R[/b] to reload configuration instantly.
[*] 🌐 [b]Multi-Language[/b]: Automatically translates item names and labels based on your game language.
[/list]

[hr][/hr]

[size=4][b]Controls[/b][/size]

[list]
[*] [b]5, 6, 7, 8[/b]: Toggle Accessory Slots 1–4.
[*] [b]Alt + H[/b]: Toggle HUD visibility.
[*] [b]Alt + F7[/b]: Toggle HUD layout editor.
[*] [b]Alt + R[/b]: Reset HUD position (in Editor) / Reload config settings.
[*] [b]Arrow Keys / Symbols[/b]: Move and scale HUD (in Editor mode).
[/list]
