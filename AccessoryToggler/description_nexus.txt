[size=5][b]Accessory Toggler[/b][/size]

Instantly equip or unequip accessories (like the Ring of Mercy or thermal underwear) using hotkeys without opening your inventory. Includes a customizable on-screen HUD.

[size=4][b]Features[/b][/size]

[list]
[*] [b]Quick Hotkey Swapping[/b]: Toggle accessory slots 1-4 instantly (Default: [b]5[/b], [b]6[/b], [b]7[/b], [b]8[/b]).
[*] [b]Interactive Status HUD[/b]: View equipped items and their active status. You can now hide/show the HUD using [b]Alt + H[/b].
[*] [b]Adjustable Slots[/b]: Customize the HUD to only show 1 to 4 slots via [b]SlotsToShow[/b] in your config.
[*] [b]HUD Editor[/b]: Press [b]Alt + F7[/b] to edit HUD layout. Use Arrows to move and [b]+[/b]/[b]-[/b] (or brackets/slash/period keys for compact keyboards) to scale. Press [b]Alt + R[/b] to reset.
[*] [b]Auto-Saving & Reloading[/b]: Saves layout changes automatically. Press [b]Alt + R[/b] outside edit mode to reload config on the fly.
[*] [b]Localization[/b]: Supports all standard game languages automatically.
[/list]

[size=4][b]Quick Controls[/b][/size]

[list]
[*] [b]5, 6, 7, 8[/b]: Toggle Accessory Slots 1-4.
[*] [b]Alt + H[/b]: Toggle HUD Visibility.
[*] [b]Alt + F7[/b]: Toggle HUD Editor.
[*] [b]Alt + R[/b]: Reset HUD (in Editor) or Reload Config (normal mode).
[*] [b]Arrows / Brackets & Symbols[/b]: Move / Scale HUD.
[/list]
