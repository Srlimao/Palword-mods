## 2024-06-25 - Defer Expensive Deduplication in UE4SS Actor Scanners
**Learning:** In UE4SS Lua, fetching an actor's full name via `actor:GetFullName()` inside a `pcall` is an extremely expensive string allocation and reflection operation. Performing this deduplication step unconditionally for all actors in the level (which can number in the hundreds or thousands) before filtering by distance causes significant frame hitches and GC spikes.
**Action:** Defer deduplication checks that rely on expensive C++ string generation until *after* fast, basic spatial checks (`IsWithinDistanceSq`) have passed. This ensures the expensive operation is only performed for the small subset of actors that are actually relevant (e.g., within the HUD range).
