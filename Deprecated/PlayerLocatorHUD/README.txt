=========================================
Palworld Player Locator HUD Mod
=========================================
This client-side mod displays floating 3D text overlays above all other players on the server, showing their names and real-time distances, even if they are on the other side of the map (outside network replication range).

This mod is highly optimized to run with ZERO performance impact.

-----------------------------
Requirements
-----------------------------
- UE4SS (updated for Palworld v1.0 or higher)

-----------------------------
Installation (Manual)
-----------------------------
1. Extract the "PlayerLocatorHUD" folder into your game's UE4SS Mods folder:
   ...\UE4SS\Mods\
   
2. Open the "mods.txt" file located in that same folder:
   ...\UE4SS\Mods\mods.txt
   
3. Add the following line at the bottom of the file to enable the mod:
   PlayerLocatorHUD : 1

4. Save "mods.txt" and launch the game.

-----------------------------
Shortcuts
-----------------------------
- Alt + F7 : Enable or disable the Player Locator HUD mod.
- Alt + F10 : Toggle the display style (switch between full box and simple text).
